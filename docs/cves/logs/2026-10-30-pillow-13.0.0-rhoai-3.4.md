## Notes

- Pillow 13.0.0 was already mirrored on all four rhoai-3.4 index flavors
  (cpu-ubi9 build -2, cuda12.9-ubi9 build -8, cuda13.0-ubi9 build -8,
  rocm6.4-ubi9 build -12), so no frozen-index update was needed.
- llmcompressor 0.10.0.3 declares `pillow<13.0.0`; upstream relaxes the cap
  only from llmcompressor >=0.13.0, which is not mirrored on the rh-index.
  Added a `pillow>=13.0.0` override-dependency to both pytorch+llmcompressor
  pyprojects (established repo pattern, same as datasets/fsspec/ray/onnx).
  Caveat: llmcompressor 0.10.0.3 runs against Pillow 13 without
  upstream-declared support.
- Lockfiles were regenerated with `PYLOCKS_CI_CHECK=1` so each lock kept its
  committed `--exclude-newer` cutoff (2026-10-23T12:13:42Z); Pillow 13.0.0 is
  the only pinned change in every lockfile.
- `make test` green with `NOTEBOOKS_DOWNGRADE_BASE_REF` pointing at the PR
  base (CI parity; a bare local run compares against `origin/main` and flags
  pre-existing branch-vs-main deltas like boto3/feast).
- Konflux: PR-level builds fired automatically on PR open; the
  `runtime-pytorch-llmcompressor` pipelinerun (label-gated, no CEL path
  filter) joined on the follow-up push. Its comment trigger, if ever
  needed, is `/build-runtime-pytorch-llmcompressor-cuda`.
